# 下一阶段目标：现场使用减负（v0.5）

2026-10-31 用户确认重新设立目标并继续推进。此阶段在 v0.4 功能基础上提升可用性，原 roadmap.md 中未完成的部署/真实设备/负载/课堂验证继续保留。公开部署仍按用户要求暂缓，不使用 Docker。

- [ ] **H01 主持台处理顺序**：固定当前检查点、人数及下一步；按待处理、协作处理中、等待参与者确认分组，前序问题不消失；人员和高级操作按需展开。
- [ ] **H02 参与端动作引导**：只突出一条当前建议，区分看更正、查看办法、确认恢复、继续操作、完成；不自动替人完成或重置状态。
- [ ] **H03 统计与权限文案一致**：澄清不显示故障恢复指标；已批准暂不参与隐藏状态提交；零参与范围不误报等待入场；演示管理按钮仅主持可见。
- [ ] **H04 首次使用更快**：默认只显示步骤标题和完成标准，其余配置折叠；提供可直接使用的本地模板入口。验证快速创建和模板两条路径。
- [ ] **H05 命令复制与预期输出**：检查点可按环境提供命令、说明及预期结果，一键复制；只复制文本，不自动执行命令；模板保留配置。
- [ ] **H06 统一资源栏**：房间内统一提供官方链接、课件和练习资源；主持管理、参与者查看，安全校验 URL；不要求先做文件上传服务。
- [ ] **H07 课后未解决事项交接**：参与者可查看/导出自己的待跟进事项与收到的办法；主持导出跟进清单；明确访问及保留期限，撤销/删除后不可访问，不泄露其他参与者信息。
- [ ] **H08 复盘结论优先**：先展示最耗时步骤、仍未解决的问题、已自报恢复的办法，再显示明细。指标是自报和时间记录，不生成教学效果评分。

验收：使用现有回归加必要的新权限/状态不变量测试，实际走通主持和参与端流程，并更新 README、版本说明、截图。只有代码、测试、浏览器和文档证据齐全才勾选；主观省心程度仍需真实带练验证。

执行顺序：H01–H03 → H04 → H05/H06 → H07/H08；期间继续收取持续测试结果和修复已观察到的问题。不会把新增功能当作已经证明产品价值。
