# v0.5：现场减负与课后交接

主持现场分组处理问题，参与端展示当前建议；空白/内置模板创建、精简步骤表单、按环境命令复制和统一资源链接。参与者导出个人未完成事项和收到的办法，主持导出跟进名单；复盘先显示耗时、未解决问题和自报恢复，再展开明细。不据此生成能力评分或答复效果因果结论。

## 升级

停止服务并另存 SQLite 备份后更新代码，按原生脚本重启。迁移为 schema user_version 7，追加资源和课后访问到期字段，保留旧记录及身份；升级前自动生成 pre-v*.bak。新结束的房间参与访问保留七天，旧已结束房间保留原访问规则。到期仅拒绝参与访问，数据库、备份和下载文件不会自动销毁。

回退须停止服务，检出旧版本并使用升级前备份；不要用旧代码操作新库。
